# OUTSOURCE STUDIO

Website giới thiệu dịch vụ quay & dựng video quảng cáo.

- `index.html` — trang dành cho khách hàng (video mẫu, bảng giá, đặt dịch vụ)
- `cong-tac-vien.html` — trang dành cho cộng tác viên (đăng ký nhận việc)
- `assets/config.js` — thông tin liên hệ, video mẫu, gói dịch vụ, link Google Sheet

Form trên web gửi dữ liệu về Google Sheet qua Google Apps Script.
Trang tĩnh, không cần build: bật GitHub Pages cho nhánh `main` là chạy.
